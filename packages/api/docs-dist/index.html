Resttek API (1.0.0)

Download OpenAPI specification:

API REST de Resttek para la gestión de restaurantes: empleados, ingredientes, platos y pedidos.

Autenticación. Los endpoints protegidos exigen una cabecera Authorization: Bearer <token>. El token JWT se obtiene en /auth/login o /auth/register, caduca a las 8 horas y contiene { id, role, restaurantId }.

Roles. admin, manager, camarero, cocinero y cliente.

Formato de errores. Actualmente la API devuelve dos formatos distintos:

  • { "error": "<mensaje>" } (middlewares de autenticación y /orders).
  • { "error": "<NombreDelError>", "message": "<mensaje>" } (resto de endpoints, vía errorHandler).
